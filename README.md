<h1 align="center">Smija</h1>
<p align="center"><img src="https://img.shields.io/github/v/tag/cide0/snake-og?label=latest%20version&style=flat-square"/></p>

This is a `Java`-based version of the classic game **Snake**, which runs in [Greenfoot](https://www.greenfoot.org/home), a `Java`-based IDE to learn the basics of OOP.

I created this game as a school project with a team of 3 other students in 10th grade.

It used to also have a `MySQL` database connected to store high scores, but it is currently not available as this database was hosted by my teacher and I haven't set up a new one.

<p align="center"><img src="./textures/body2.png" alt="icon" width="60"/></p>

## Current Features

- Complete classic **Snake** game functionality:
  - Move the snake by using the arrow keys.
  - Eat apples to grow longer and increase the score.
  - One apple is spawned at a time, and a new one spawns randomly after the previous one is eaten.
  - Avoid colliding with yourself or the walls.
  - Game over message and final score output.
  - Fully custom pixel art textures made by me.

- As explained above, after the game is over, it tries to save the score to a `MySQL` database, but this is currently not available and will fail.

<p align="center"><img src="./textures/body2.png" alt="icon" width="60"/></p>

## Setup

1. Download and install [Greenfoot](https://www.greenfoot.org/download).

2. Clone this repository or download the ZIP file and extract it.

3. Open **only** the `smija` folder in Greenfoot and click on `Run`.
