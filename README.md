Welcome to my first ever real coding project, which was the start of it all and got me into my career as a software developer. 

This is a `Java` based version of the classic snake game, which runs in [Greenfoot](https://www.greenfoot.org/home), a Java-based IDE for learning programming.

I created this game as a school project with a team of 3 other students in the 10th grade.

It was my first real touch with OOP programming and really sparked my interest in programming and software development.
